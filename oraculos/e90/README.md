# Referencias candidatas del corpus E90

Estos archivos son borradores de referencia y metadatos de generación. No contienen resultados experimentales ni calificaciones de los autores. El estado es CANDIDATO_NO_CONGELADO y revisado_por_autores permanece falso.

`inventario_candidato.csv` enumera los 65 archivos de entrada reales. `artefactos_candidatos.json` vincula originales y auxiliares con hashes y transformaciones simuladas. `campos_candidatos.json` distingue presencia y ausencia. `fragmentos_candidatos.json` conserva la referencia primaria del documento; los chunks técnicos se mapearán después para cada indexación. `consultas_candidatas.json` contiene 30 referencias previas a ejecuciones de modelos. `cuit_candidatos.json` espera consultas manuales del equipo.

Una comprobación estructural exitosa no acredita calidad de OCR/IA, adecuación semántica de las referencias, licitud de un CUIT candidato, revisión de autores ni aceptación de IA-D/IA-M. La información de demo PD-07 no se modifica ni se importa a estas particiones.
