# Fuentes contractuales públicas aprobadas para E90

Fecha: 22/10/2026. Se recibieron aprobaciones expresas para las cuatro fuentes. Se verificaron los avisos de las páginas de publicación y los archivos/textos en blanco utilizados. El registro detallado conserva URL exacta del archivo, versión, SHA-256, licencia, atribución, extractos originales, localizadores y traducciones/modificaciones en `herramientas/corpus_e90/plantillas/contratos.json`.

No se usan logotipos, imágenes de marca, firmas, datos de personas, materiales privados ni componentes de terceros excluidos. Las licencias de componentes mencionadas dentro de una cláusula no son la licencia del documento.

Se tradujeron, abreviaron y reorganizaron cláusulas seleccionadas, se introdujeron fichas sintéticas y se omitieron procedimientos públicos no pertinentes. En los dos contratos extensos se agregan extractos originales atribuidos para conservar correspondencia de fuente, introduciendo contenido bilingüe declarado en DIF-E90-05. La revisión de las traducciones y de la representatividad queda pendiente de los autores. No se presentan los documentos como modelos jurídicamente validados para Argentina.

El PDF argentino inicialmente localizado en una búsqueda no se utilizó ni se incorporó como fuente del corpus. PD-07 no se modificó y sus originales no se trasladaron a medición.
